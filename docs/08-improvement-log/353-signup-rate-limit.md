# 공개 회사 가입 횟수 제한 (#353)

- 문제와 원인 — 인증 전 회사 가입 경로에는 요청 횟수 검사가 없어 같은 접속자가 회사를 반복 생성할 수 있었다.
- 해결 — 요청 본문 검증 후 회사 생성 전에 IP별 가입 횟수를 PostgreSQL에서 확정한다. 같은 IP의 첫 시도부터 창을 시작하며 만료되면 다음 시도에서 다시 센다. 원문 주소 대신 비밀키 기반 HMAC만 저장한다.
- 결과 — 2회 한도에서 같은 IP의 동시 요청 6개 중 2개만 통과하는지 자동 테스트한다. 초과 응답에는 다음 시도까지의 초를 담는다.
- 운영 정리 — DB 소유자 작업으로 다음 SQL을 매일 실행할 수 있다. 같은 IP가 다시 방문하면 정리 전에도 만료된 창을 자동 재사용한다.

```sql
DELETE FROM public.signup_rate_limits WHERE expires_at <= now();
```
