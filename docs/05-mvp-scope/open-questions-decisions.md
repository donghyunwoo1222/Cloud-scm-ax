# 열린 질문 정리와 결정 (2026-11-03, 6단계 시작 전, 이슈 반영 완료)

기준 문서: claude/ax-design-summary.md, claude/mvp-scope-summary.md, claude/service-planning-summary.md

## 확정 (사용자 결정)
- 이유 문구: 규칙 기반 문장 틀, LLM 다듬기는 Could (C1)
- 품목에 기본 공급업체 1개 지정 필드 포함, 필수 입력
- 리드타임: 공급업체별로 저장(0 이상 정수). 같은 공급업체에 한 번에 주문한 품목은 같이 들어오므로 리드타임이 같다는 사용자 의견 반영. 품목의 리드타임 = 기본 공급업체의 리드타임. 품목별 예외 값은 후순위
- 출고 유형(판매/폐기·파손/기타) 구분, 판매 출고만 일평균 판매량에 포함(R9). 판매 채널은 유형이 판매일 때만 필수
- 실사 차이: 사유 필수 "조정" 이력으로 기록(R10), 재고=이력 합계 유지. 별도 화면 없이 출고 등록 화면의 유형 "재고 조정". 입력은 조정 방향(증가/감소)과 수량(1 이상 정수)을 따로 받아 이력에 부호 반영
- 부분 입고 후 취소 불가(입고가 한 번도 없는 발주만 취소 가능). 부분 입고 후에도 ORDERED 유지, 누적 입고량 = 발주 수량이면 RECEIVED
- 승인 생략 없음: 관리자가 직접 만든 발주도 승인 1번
- 발주 없는 입고는 "직접 입고"로 허용, 초과 입고 차단
- 삭제 정책: 이력 있는 공급업체·품목은 삭제 대신 비활성(is_active). 비활성은 새 발주·입출고 선택 목록에서만 숨김
- 직원 초대: 관리자가 계정 직접 생성(이메일+임시 비밀번호), 이메일 초대는 후순위
- 추천 계산 시점: 추천 화면을 열거나 버튼을 누를 때 계산 (아키텍처 설계에서 확정)
- 위 결정 사항은 이슈 #2~#8, #11, #12에 모두 반영 완료
