# Cloud SCM 사용 가이드

이 문서는 안내 챗봇이 답할 때 근거로 삼는 사용자용 가이드입니다. 화면·메뉴·버튼을 바꾸는 PR 은 이 문서도 함께 고칩니다. 서버 상수가 나오는 문장(링크 유효 기간, 회신 횟수 한도, 파일 크기·행 수 한도 등)은 상수가 바뀔 때 함께 확인합니다.

## [G-START] 처음 시작과 메뉴 구성
화면: /dashboard
대상: 관리자·담당자
상태: 사용 가능
1. 로그인하면 먼저 "대시보드"가 열립니다. 담당자는 이메일과 비밀번호만 넣으면 바로 열리고, 관리자는 비밀번호 다음에 이메일로 온 6자리 인증코드(유효 10분)를 입력해야 열립니다. "오늘 할 일"과 발주 검토가 필요한 품목을 볼 수 있어요.
2. 왼쪽 메뉴는 "재고 업무"(재고 현황, 품목, 입고 등록, 출고 등록, 판매 가져오기, 품목 가져오기, 품목·입고 가져오기), "구매 업무"(발주 추천, 발주, 공급업체), "회사"(회사 정보, 슬랙 연결) 순서입니다. 관리자에게만 "관리" 아래 "사용자 관리"가 더 보입니다.
3. 등록된 품목이 하나도 없으면 "첫 재고 설정" 칸이 나옵니다. 공급업체 등록 → 품목 등록 → 첫 입고 순서로 진행하세요.
4. 화면이 좁으면 위쪽 왼쪽 막대 3줄 버튼으로 메뉴를 열고, 내 정보 옆 "로그아웃"으로 나갑니다.

## [G-SUPPLIER] 공급업체 등록 (입고 소요일)
화면: /suppliers
대상: 관리자·담당자
상태: 사용 가능
1. 왼쪽 메뉴에서 "공급업체"를 누르고 "공급업체 등록"을 펼칩니다.
2. "업체명"과 "입고 소요일(일)"은 꼭 적습니다. 입고 소요일은 주문하고 물건이 올 때까지 걸리는 일수이며, 발주 추천 계산에 쓰입니다.
3. 필요하면 담당자, 연락처, 이메일, 지불조건, 메모도 적습니다. 발주서를 메일로 보내려면 이메일이 있어야 해요.
4. "등록"을 누르면 목록에 나타납니다. 업체 이름을 누르면 상세 화면에서 비활성으로 바꿀 수 있고, 비활성 업체는 새 발주에서 빠집니다. 삭제는 없습니다.

## [G-PRODUCT] 품목 등록 (기본 공급업체와 안전재고)
화면: /products
대상: 관리자·담당자
상태: 사용 가능
1. 왼쪽 메뉴에서 "품목"을 누르고 "품목 등록"을 펼칩니다. 활성 공급업체가 없으면 먼저 공급업체를 등록하라는 안내가 나옵니다.
2. "SKU", "품목명", "재고 단위", "재고 단위 단가(원)", "기본 공급업체"는 꼭 적습니다. 품목마다 기본 공급업체가 하나 있어야 합니다.
3. "안전재고"는 갑자기 많이 팔려도 버틸 여유 수량입니다. 발주 추천 계산에 쓰이니 품목에 맞게 적어 두세요. 색상, 사이즈, 규격, 그룹 코드는 구분용이라 비워도 됩니다.
4. 박스·팩 단위로 사는 품목은 발주단위, 환산계수, 발주단위 단가를 채웁니다. 환산계수는 박스 1개에 들어 있는 낱개 수입니다.
5. "등록"을 누릅니다. 고칠 때는 목록에서 품목 이름을 눌러 상세 창을 열고 "수정"을 누른 뒤 "수정 저장"을 누릅니다. 더 쓰지 않는 품목은 같은 수정 폼의 "비활성" 버튼으로 바꿉니다. 삭제는 없습니다.

## [G-PRODUCT-IMPORT] 품목 가져오기
화면: /product-import
대상: 관리자·담당자
상태: 사용 가능
1. 왼쪽 메뉴에서 "품목 가져오기"를 누릅니다. 양식이 없으면 "엑셀 템플릿" 또는 "CSV 템플릿"을 내려받아 채웁니다.
2. 파일(.csv 또는 .xlsx, 5MB·5,000행 이하)을 끌어 놓거나 눌러서 고릅니다. 템플릿과 같은 양식이면 열이 자동으로 맞춰지고 미리보기까지 실행됩니다.
3. 열이 맞는지 확인하고 "미리보기"를 누릅니다. 신규 등록할 품목과 기존 품목에서 바뀌는 값, 문제 있는 줄이 보입니다.
4. 새 품목이 있으면 미리보기 안에서 기본 공급업체를 고릅니다.
5. 반영 버튼 하나를 누릅니다. 버튼 글자는 신규와 수정이 함께 있으면 "신규 ○개 등록, 기존 ○개 수정", 신규만 있으면 "신규 ○개 등록", 수정만 있으면 "기존 ○개 수정"입니다. 같은 SKU 가 이미 있으면 수정으로 처리되고 파일의 빈 칸은 기존 값을 바꾸지 않습니다. 이 화면은 재고를 바꾸지 않으니 처음 재고는 "품목·입고 가져오기"로 넣으세요.

## [G-RECEIPT] 직접 입고
화면: /receipts
대상: 관리자·담당자
상태: 사용 가능
1. 왼쪽 메뉴에서 "입고 등록"을 누릅니다. 발주서에 연결된 입고는 "입고 대기 발주 보기"로 발주 화면에서 하고, 반품처럼 발주서가 없는 입고만 "직접 입고 입력"을 씁니다.
2. 품목을 검색해 고릅니다. 고르면 현재고가 함께 보입니다.
3. 수량, 입고일, 필요하면 메모를 적고 "등록"을 누릅니다. 입고일은 오늘이나 과거 날짜만 쓸 수 있습니다.
4. 등록하면 현재고가 바로 늘고 아래 "최근 입고 10건"에 나타납니다. 잘못 넣었다면 이력을 지우는 대신 "재고 현황"에서 정정합니다.

## [G-SHIPMENT] 출고 (판매, 폐기, 기타)
화면: /shipments
대상: 관리자·담당자
상태: 사용 가능
1. 왼쪽 메뉴에서 "출고 등록"을 누릅니다.
2. 품목을 고르고 "유형"에서 판매, 폐기, 기타 출고 중 하나를 고릅니다. 판매는 발주 추천 계산에 쓰이니 폐기·기타 출고와 구분해서 고르세요.
3. 판매를 고르면 "판매 채널"(스마트스토어, 자사몰, 기타)도 고릅니다.
4. 수량과 출고일을 적고 "등록"을 누릅니다. 현재고보다 많이 출고하면 등록되지 않습니다.
5. 등록하면 아래 "최근 출고·조정 10건"에 나타납니다.

## [G-SALES-IMPORT] 판매 가져오기
화면: /sales-import
대상: 관리자·담당자
상태: 사용 가능
1. 왼쪽 메뉴에서 "판매 가져오기"를 누릅니다. 쇼핑몰 주문 파일(.csv 또는 .xlsx)을 올리면 판매 출고로 한 번에 기록됩니다. 양식이 없으면 "엑셀 템플릿" 또는 "CSV 템플릿"을 씁니다.
2. 열 지정에서 "상품 코드(SKU)", "수량", "날짜(주문일·발송일)", "고유 주문번호"를 확인합니다. 같은 주문이 두 번 반영되지 않게 고유 주문번호로 걸러냅니다.
3. 파일에 상태 열이 있으면 "반영할 상태"에서 출고가 끝난 값(예: 배송중, 배송완료)만 골라 취소 주문을 뺍니다. 반영할 상태를 하나도 고르지 않으면 모든 행이 "반영하기로 고르지 않은 상태"로 건너뛰어져 버튼이 "반영할 행 없음"이 됩니다.
4. "미리보기"를 눌러 반영될 건수와 건너뛰는 건, 문제 있는 줄을 확인합니다.
5. "판매 채널"을 고르고 "○건 반영"을 누릅니다. 문제 행이 있으면 "문제 행 ○건 제외하고 반영"을 체크해야 나머지만 반영됩니다. 반영한 이력은 되돌릴 수 없고, 잘못된 건은 재고 현황에서 정정합니다.

## [G-RECEIPT-IMPORT] 품목·입고 가져오기
화면: /receipt-import
대상: 관리자·담당자
상태: 사용 가능
1. 왼쪽 메뉴에서 "품목·입고 가져오기"를 누릅니다. 처음 재고를 한꺼번에 넣거나 입고 목록 파일을 올릴 때 씁니다.
2. 파일(.csv 또는 .xlsx, 5MB·5,000행 이하)을 올리고 열을 확인한 뒤 "미리보기"를 누릅니다. 수량 열을 고르지 않으면 품목만 등록됩니다. 머리글 이름이 템플릿과 다르면(예: "SKU/수량") 수량 열이 자동으로 골라지지 않고 "사용 안 함"으로 남을 수 있으니, 수량 열이 "사용 안 함"으로 남아 있지 않은지 꼭 확인하세요.
3. 없는 상품 코드는 새 품목으로 등록됩니다. 새 품목이 있으면 "기본 공급업체"를 고르세요. 새 품목은 모두 같은 업체로 등록되니 업체가 여러 곳이면 파일을 나눠 올립니다.
4. 반영 버튼 하나를 누릅니다. 버튼 글자는 "새 품목 ○개 등록 + 입고 ○건"이고, 새 품목이 없으면 "입고 ○건"입니다. 이미 있는 품목의 정보는 바뀌지 않고, 입고는 발주 없는 직접 입고로 기록됩니다.
5. 반영한 입고는 되돌릴 수 없고, 잘못된 건은 재고 현황에서 정정합니다.

## [G-STOCK] 재고 보기와 실사 조정
화면: /inventory
대상: 관리자·담당자
상태: 사용 가능
1. 왼쪽 메뉴에서 "재고 현황"을 누릅니다. 품목별 현재고, 발주 진행 중 수량, 안전재고와 상태(부족, 정상, 판단 불가)가 보입니다. 검색창과 "재고 상태" 선택으로 좁혀 볼 수 있습니다.
2. 품목 이름을 누르면 그 품목의 재고 추이와 입출고 이력이 아래에 나옵니다. 이력은 유형과 기간으로 거를 수 있습니다.
3. 창고에서 센 수량이 화면과 다르면 위쪽 "실사 조정"을 누릅니다. 출고 등록 화면의 유형이 "실사 조정"으로 열립니다.
4. 품목을 고르고 방향(감소 (실제가 더 적음) 또는 증가 (실제가 더 많음)), 수량, 조정일, 사유를 적고 "등록"을 누릅니다. 사유는 꼭 적어야 합니다.

## [G-CORRECTION] 잘못 입력한 입출고 정정
화면: /inventory
대상: 관리자·담당자
상태: 사용 가능
1. 입출고 이력은 고치거나 지울 수 없습니다. 실수는 정정 이력을 더해 바로잡습니다.
2. "재고 현황"에서 품목 이름을 눌러 이력을 열고, 고칠 이력 줄의 "정정"을 누릅니다. 정정할 수 없는 줄에는 버튼이 없습니다.
3. "정정 수량"과 "사유"를 적습니다. 정정 수량은 원래 수량을 넘을 수 없고, 입력 칸 옆 안내에서 가능한 최대 수량을 볼 수 있습니다. 사유는 꼭 적어야 합니다.
4. "정정 등록"을 누르면 원래 이력과 반대 방향으로 정정 이력이 쌓이고 현재고가 바뀝니다. 정정을 다시 정정할 수는 없습니다.
5. 발주서에 연결된 입고는 발주서가 "발주함" 상태일 때만 정정할 수 있습니다.

## [G-RECO] 발주 추천 보는 법과 제외 사유
화면: /recommendations
대상: 관리자·담당자
상태: 사용 가능
1. 왼쪽 메뉴에서 "발주 추천"을 누릅니다. 최근 30일 판매를 기준으로 지금 발주가 필요한 품목이 나옵니다.
2. 표의 "가용재고"는 현재고에 이미 주문해서 오는 중인 수량을 더한 값입니다. 이 값이 "재주문점" 이하이면 추천됩니다. 상태는 "품절 위험" 또는 "발주 필요"로 표시됩니다.
3. 품목 줄의 "자세히"를 누르면 계산 이유가 펼쳐집니다.
4. 발주할 품목을 체크하고 필요하면 발주 수량을 고친 뒤 "발주서 초안 만들기"를 누릅니다. 공급업체별로 "작성 중" 발주서가 만들어지며, 이미 초안에 든 품목은 선택할 수 없습니다.
5. 아래 "추천에서 제외된 품목"에는 계산하지 않은 품목과 사유가 나옵니다. "기본 공급업체가 비활성입니다. 품목 정보를 확인하세요", "데이터 부족"(첫 입출고 후 14일이 지나지 않음), "최근 30일 판매 없음" 중 하나입니다.

## [G-PO-CREATE] 발주서 작성
화면: /purchase-orders/new
대상: 관리자·담당자
상태: 사용 가능
1. 왼쪽 메뉴에서 "발주"를 누르고 "발주서 작성"을 누릅니다. "발주 추천"에서 "발주서 초안 만들기"로 시작해도 됩니다.
2. "공급업체"를 고르고 필요하면 약속 납기, 납품장소(비우면 회사 주소), 지불조건(비우면 공급업체 기본값), "기타 요청사항"을 적습니다. 기타 요청사항은 발주서에 그대로 나가니 내부 메모는 적지 마세요.
3. 품목 줄에서 품목을 검색해 고르고 수량과 단가를 확인합니다. "줄 추가"로 줄을 늘리고, "기본 품목 추가"를 누르면 그 업체가 기본 공급업체인 품목이 한꺼번에 들어옵니다. 추천이 있는 품목은 수량도 채워집니다.
4. "초안 저장"을 누르면 "작성 중" 발주서가 만들어집니다. 공급업체마다 작성 중인 발주서는 하나만 둘 수 있고, 이미 있으면 기존 발주서를 여는 링크가 나옵니다.
5. 작성 중에는 발주서 화면의 "수정"으로 고치고 "변경 저장"을 누릅니다. 승인한 뒤에는 고칠 수 없습니다.

## [G-PO-APPROVE] 발주서 승인 (관리자만)
화면: /purchase-orders
대상: 관리자
상태: 사용 가능
1. 왼쪽 메뉴에서 "발주"를 누르고 발주번호를 눌러 "작성 중" 발주서를 엽니다.
2. 회사 정보가 비어 있으면 안내 문구와 "회사 정보 입력하기" 링크가 나옵니다. 승인하면 고칠 수 없으니 먼저 채우는 것이 좋습니다.
3. "승인"을 누릅니다. 회사 정보가 비어 있으면 한 번 더 확인창이 뜹니다.
4. 승인되면 상태가 "승인됨"이 되고 "발주서 문서"를 볼 수 있습니다.
5. 담당자에게는 "승인" 버튼이 없고 "승인은 관리자만 할 수 있습니다. 관리자에게 승인을 요청하세요." 안내가 보입니다.

## [G-PO-SEND] 발주 메일 보내기와 주문 완료 표시
화면: /purchase-orders
대상: 관리자·담당자
상태: 사용 가능
1. 왼쪽 메뉴에서 "발주"를 누르고 "승인됨" 발주서를 열어 "발주서 문서"를 누릅니다. 이 화면에서 "인쇄 · PDF 저장"과 "엑셀"로도 받을 수 있습니다.
2. "메일 보내기"를 누르면 받는 사람(공급업체 이메일), 제목, 첨부(PDF·엑셀)가 미리보기로 나옵니다. 본문 첫 문단만 고칠 수 있고 나머지 품목표와 조건은 발주서와 같은 값으로 고정됩니다. 공급업체 이메일이 없으면 보낼 수 없으니 "공급업체 정보에서 이메일 넣기" 링크로 먼저 넣으세요.
3. 아래 "메일 보내기" 버튼을 누르고 확인창에서 확인하면 발송되고 발주서가 "발주함" 상태로 바뀝니다.
4. 이미 "발주함"인 발주서는 "다시 보내기"가 나오고, 마지막 발송 시각과 주소가 안내됩니다. 다시 보내기 확인창에는 "다시 보낼까요? 이전 발송도 이력에 남습니다."라고 나오며, 다시 보내도 이전 발송은 지워지지 않습니다.
5. 발주서 화면의 "마지막 발송"에서 가장 최근 발송 시각과 주소를 볼 수 있고, 같은 화면 아래 "메일 발송 이력"에는 발송할 때마다 종류, 시각, 보낸 사람, "받는 주소", "결과"가 최신순으로 쌓입니다. 발주서 문서 화면에서 "메일 보내기"를 열었을 때도 메일 창 아래에 같은 이력이 보입니다. 이력이 많으면 "이전 발송 더 보기"를 누릅니다.
6. "결과"가 "성공"이어도 메일 서버로 보낸 것까지만 확인된 것이고, 공급업체가 받았는지는 알 수 없습니다. 실패하면 "실패: 메일 서버 로그인에 실패했습니다.", "실패: 메일 서버가 받는 주소를 거부했습니다.", "실패: 메일 서버가 시간 안에 응답하지 않았습니다.", "실패: 메일 서버에 연결하지 못했습니다.", "실패: 발송 중 오류가 났습니다." 중 하나가 보이고 실패한 시도도 이력에 남습니다. 드물게 "메일은 나갔으나 기록 저장에 실패했습니다"가 보이면 메일은 보내진 것입니다.
7. 메일 없이 전화 등으로 주문했다면 발주서 화면의 "공급업체에 주문 완료 표시"를 눌러 "발주함"으로 바꿉니다.

## [G-PO-RECEIVE] 발주 입고 (부분 입고)
화면: /purchase-orders
대상: 관리자·담당자
상태: 사용 가능
1. 왼쪽 메뉴의 "입고 등록"에서 "입고 대기 발주 보기"를 누르거나 "발주"에서 "발주함" 발주서를 엽니다.
2. "입고 등록"을 누르면 "이번 입고" 표가 열립니다. 아직 덜 받은 품목만 남은 수량과 함께 보입니다.
3. 실제로 받은 수량만 입력합니다. 비워 둔 품목은 이번 입고에서 빠집니다. 박스로 발주한 품목은 박스 또는 낱개 단위를 고를 수 있습니다.
4. "입고일"을 확인하고 "입고 확정"을 누릅니다. 남은 수량보다 많이 넣으면 저장되지 않습니다.
5. 일부만 받으면 발주서는 "발주함"으로 남고 남은 수량이 계속 표시됩니다. 모든 품목을 다 받으면 "입고 완료"가 되고 입고한 수량만큼 현재고가 늘어납니다.

## [G-PO-CLOSE] 남은 수량 마감
화면: /purchase-orders
대상: 관리자·담당자
상태: 사용 가능
1. 일부만 입고되고 나머지는 더 받지 않기로 했을 때 씁니다. "발주함" 상태이고 입고 기록이 한 번 이상 있는 발주서에만 "잔량 마감" 버튼이 나옵니다.
2. "잔량 마감"을 누르면 마감될 품목과 수량이 안내됩니다.
3. "마감 사유"를 적습니다. 사유는 꼭 적어야 합니다.
4. "마감 확정"을 누르면 발주서가 "입고 완료"로 닫히고 "(잔량 마감)"이 표시됩니다. 되돌릴 수 없고, 남은 수량을 다시 받으려면 새 발주서를 만들어야 합니다.

## [G-PO-SUPPLIER-REPLY] 공급업체 확인 링크와 납기 회신, 직원 대신 입력
화면: /purchase-orders
대상: 관리자·담당자
상태: 사용 가능
1. 발주 메일에 확인 링크가 들어 있으면 공급업체가 로그인 없이 링크를 열어 발주 내용(단가와 금액은 보이지 않음)을 확인하고 "확인하고 보내기"를 누를 수 있습니다. 원하면 회신 납기도 고릅니다. 링크는 보낸 날부터 30일 동안 쓸 수 있고, 납기를 바꾸는 회신은 5번까지 가능합니다.
2. 회신이 오면 발주서 화면에 "공급업체 확인" 시각과 "회신" 납기가 나타납니다. 회신 납기가 약속 납기보다 늦으면 "약속보다 늦은 회신" 표시가 붙고, 납기 지연은 회신 날짜 기준으로 판단됩니다.
3. 확인 링크가 메일에 들어가지 않는 설정이면 공급업체는 링크로 회신할 수 없습니다. 이때는 전화나 메일로 받은 회신을 직접 기록하세요.
4. "발주함" 발주서에서 "회신 기록"을 누르고, 받은 "회신 납기"(비우면 확인만 기록)와 "받은 경로·메모"(꼭 필요)를 적은 뒤 "기록"을 누릅니다. 기록한 사람은 변경 이력에서 볼 수 있습니다.
5. 입고 완료나 취소된 발주서에는 회신을 기록할 수 없습니다.

## [G-PO-CANCEL] 발주서 취소
화면: /purchase-orders
대상: 관리자·담당자
상태: 사용 가능
1. 입고 기록이 한 번도 없는 "작성 중", "승인됨", "발주함" 발주서만 취소할 수 있습니다. 발주서를 열면 "취소" 버튼이 나옵니다.
2. "취소"를 누르면 "발주서 취소" 칸이 열리고 "취소 사유"를 적습니다. "발주함" 상태에서는 사유가 꼭 필요하고, 그 밖의 상태에서는 선택입니다.
3. 발주서 메일을 이미 보낸 발주서는 취소 칸에 "공급업체에 이미 발주서 메일을 보냈습니다. 취소해도 공급업체에는 자동으로 알려지지 않으니 별도로 연락하세요." 경고가 나옵니다. 전화 등으로 "공급업체에 주문 완료 표시"만 한 발주서에는 이 경고가 없습니다.
4. "취소 확정"을 누르면 "취소됨"이 되며 되돌릴 수 없습니다.
5. 입고 기록이 있는 발주서는 취소할 수 없습니다. 남은 수량은 "잔량 마감"으로 닫습니다.

## [G-EXPORT] 목록 내보내기
화면: /products

1. "품목", "발주", "재고 현황" 화면 위쪽에 "내보내기" 버튼이 있습니다. "재고 현황"에서는 품목 이름을 눌러 입출고 이력을 열면 이력용 "내보내기"도 나옵니다.
2. 먼저 검색어나 상태 같은 조건으로 목록을 좁힙니다. 지금 보이는 조건 그대로 내보냅니다.
3. "내보내기"를 누르면 건수가 안내되고, "엑셀(xlsx)" 또는 "csv"를 고를 수 있습니다.
4. "내려받기"를 누릅니다. 건수가 너무 많으면 기간이나 조건을 좁혀 달라는 안내가 나옵니다. 발주는 품목 줄 단위로 내보내집니다.

## [G-USERS] 직원 계정 만들기 (관리자만)

2. "이름", "이메일", "임시 비밀번호"(8자 이상), "역할"(담당자 또는 관리자)을 적고 "계정 만들기"를 누릅니다.

4. 목록에서 역할을 바꾸거나 "비활성"으로 계정을 막을 수 있고, 다시 쓰려면 "다시 활성"을 누릅니다. 삭제는 없습니다.

## [G-SLACK] 슬랙 연결
화면: /slack
대상: 관리자·담당자
상태: 사용 가능
1. 왼쪽 메뉴 "회사"에서 "슬랙 연결"을 누릅니다. 슬랙에서 봇에게 재고와 발주를 물어보려면 내 계정과 슬랙을 한 번 연결해야 합니다.
2. "슬랙 연결은 아직 켜져 있지 않아요" 안내가 보이면 아직 쓸 수 없는 상태이니 관리자에게 문의하세요.
3. "연결 코드 받기"를 눌러 6자리 코드를 받습니다. 화면의 문구를 "복사"해서 10분 안에 슬랙의 봇에게 보냅니다.
4. 화면으로 돌아와 "연결 확인"(또는 "새로고침")을 누르면 "연결됨"으로 바뀝니다.
5. 연결을 끊으려면 연결된 상태에서 "연결 해제"를 누르고 확인합니다. 코드를 잘못 받았다면 "코드 취소" 또는 "새 코드 받기"를 씁니다.
